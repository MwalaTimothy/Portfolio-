# Portfolio Website Images

This folder contains images for your portfolio website. Please add the following images:

## Required Images:

### 1. **profile.jpg** (350x350px or larger, square ratio)
- Your professional headshot or portrait
- Should be high quality and well-lit
- Will be displayed as a circular image in the hero section

### 2. **about.jpg** (600x400px or larger)
- A photo that represents you or your workspace
- Could be you working, your setup, or a professional photo
- Will be displayed in the about section

### 3. **project1.jpg** (600x300px or larger)
- Screenshot or mockup of your first featured project
- Should clearly show the project interface or design

### 4. **project2.jpg** (600x300px or larger)
- Screenshot or mockup of your second featured project
- Should clearly show the project interface or design

### 5. **project3.jpg** (600x300px or larger)
- Screenshot or mockup of your third featured project
- Should clearly show the project interface or design

## Image Guidelines:

- **Format**: Use JPG or PNG format
- **Quality**: High resolution for crisp display on all devices
- **Optimization**: Compress images to keep file sizes reasonable (under 500KB each)
- **Naming**: Use exact filenames as listed above for automatic loading

## Placeholder Images:

If you don't have images ready, you can use placeholder services temporarily:
- https://picsum.photos/350/350 for profile.jpg
- https://picsum.photos/600/400 for about.jpg  
- https://picsum.photos/600/300 for project images

## Adding Your Images:

1. Place your images in this `/images/` folder
2. Make sure the filenames match exactly (case-sensitive)
3. The website will automatically load and display them
4. Test the website locally to ensure images appear correctly

Remember to replace placeholder images with your actual photos before deploying to GitHub Pages!
